Capitalia 
Proyecto en fase de desarrollo activo.

## Tecnologías Utilizadas

* **Frontend:** React, Tailwind CSS 4.
* **Backend:** Typescript.
* **ORM:** Prisma.
* **Base de Datos:** MySQL / PostgreSQL.
* **Testing de APIs:** Insomnia.

## Funcionalidades Principales

* **Gestión de Clientes:** Registro y control de personas con créditos activos.
* **Control de Préstamos:** Cálculo automático de intereses y plazos de pago.
* **Seguimiento de Cuotas:** Registro de pagos realizados y visualización de saldos pendientes.
